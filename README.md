# CreatorFlow AI

**AI 驱动的新媒体内容创作工作流助手**

CreatorFlow AI 是一个面向 AI 产品经理作品集展示的 Demo Preview，探索如何将内容创作中的重复任务组织为清晰、可配置、可持续扩展的 AI 工作流。

## 产品背景

内容创作者在日常工作中需要反复完成选题、标题、文案、封面设计和内容复盘等任务。这些环节通常分散在不同工具与页面中，流程碎片化，信息与创作经验也难以沉淀和复用。

AI 可以辅助串联这些重复环节，将零散工具能力组织成完整的内容创作工作流，同时保留创作者对内容方向和最终结果的判断。

## 产品目标

帮助小红书等新媒体平台的内容创作者提高内容生产效率，降低在重复操作和工具切换上的时间成本，并为后续接入真实模型、数据与自动化能力建立产品框架。

## 核心功能

- **AI 内容生成 Workflow**：以工作流方式组织内容创作环节，展示从创作任务到结果产出的完整路径。
- **标题 / 正文生成**：根据创作输入生成标题、正文与封面提示词等内容候选。
- **模型配置管理**：通过 Model Hub 管理文本与图片模型的配置状态。
- **Visual Studio 图片创意模块**：将内容主题转化为封面创意方向，并支持 Demo 图片候选展示。
- **Knowledge Repository 知识库框架**：提供知识条目管理、检索与内容生成引用的基础框架。
- **Mock Provider 演示模式**：在不调用外部 AI API 的情况下演示文本和图片生成流程。

## 产品架构

CreatorFlow AI 采用以 Next.js 为核心的分层结构：

```text
Next.js 前端
    ↓
API Routes
    ↓
Model Provider 抽象层
    ↓
Knowledge Repository
    ↓
Vercel Deployment
```

- **Next.js 前端**：承载工作台、内容创作、模型管理、Visual Studio 和知识库等产品界面。
- **API Routes**：提供内容生成、图片生成、模型状态、研究与知识库相关的服务端入口。
- **Model Provider 抽象层**：统一文本与图片模型的调用接口，并支持 Mock Provider。
- **Knowledge Repository**：为知识存储、检索和后续 RAG 能力提供基础框架。
- **Vercel Deployment**：作为 Next.js 项目的部署目标。

## 当前版本限制

- 当前版本为 **Demo Preview**，主要用于产品流程和交互方案展示。
- 默认使用 **Mock AI Provider** 演示生成流程，不代表生产环境中的真实模型输出。
- 未接入真实小红书数据，演示内容不代表真实平台趋势或爆款数据。
- 未接入生产级数据库，当前知识库仅为能力框架与本地演示实现。
- 当前项目不包含自动发布小红书或完整商业化系统。

## Roadmap

### Phase 1：产品 Demo

完成核心页面、内容创作流程、模型配置、Visual Studio 和知识库框架的 Demo 展示。

### Phase 2：真实大模型接入

在安全的服务端配置基础上接入真实文本与图片模型，并完善模型切换、错误处理和成本控制。

### Phase 3：数据库和 RAG

接入生产级数据库，完善知识资产管理、向量检索、引用追踪和 RAG 内容生成能力。

### Phase 4：Agent 自动化工作流

探索由 Agent 协调选题、生成、审核、视觉创意与复盘环节的自动化工作流，并保留关键节点的人工确认。
